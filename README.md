# NrfBoox Firmware Update

Up until now, those of you who built the **NrfBoox** knew it primarily as a jamming device—used mainly for Wi-Fi Jamming, Bluetooth Jamming, Wi-Fi Deauthing, and targeting various 2.4GHz protocol devices.

**What if we told you that from now on, you can use it as a full-fledged hacking device?**

### 🚀 Key Features & Upgrades

* **Evil Twin Attacks:** You can now perform Evil Twin attacks directly from the device to capture Wi-Fi passwords. When a victim inputs their credentials into the fake portal, you can view the captured password right on the device screen—no external smartphone required!
* **Enhanced Compatibility:** Fixed and improved several attacks that previously didn't work on various local device models.
* **More Attacks Coming Soon:** Additional attack vectors and performance optimizations have been integrated.

---

### 📡 Seamless Wireless Updates (Over-The-Air)

You might be wondering: *“Will I need to connect a cable and manually re-flash the firmware every time a new version comes out?”*  
We know how tedious that can be. That’s why in this release, our top priority was fixing the **OTA (Over-The-Air) Update** feature.

* **No SD Card Required:** Previously, limited GPIO pins caused issues and required an SD card (under 32GB)—something not everyone has on hand.
* **Effortless Flashing:** You no longer need an SD card or extra cables. You can now update the firmware wirelessly using your phone in just a few seconds!
